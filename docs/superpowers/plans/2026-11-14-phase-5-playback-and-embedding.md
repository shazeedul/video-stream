# Phase 5: Playback and Embedding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement secure HLS video playback and iframe embedding using Nginx `auth_request` offload to MinIO, HMAC signed playback tokens, a Video.js React player component, and a dedicated embed endpoint.

**Architecture:** Nginx acts as the high-throughput edge proxy on port 8088. When clients request `/playback/{video_id}/{asset}?token=...&expires=...`, Nginx makes an internal `auth_request` subrequest to Laravel (`/api/v1/internal/playback/auth`). Laravel validates the HMAC signature, video state (`READY`), and tenant permissions, returning `200 OK` with header `X-Tenant-Id`. Nginx then directly streams `.m3u8` playlists and `.ts` video chunks from MinIO (`videos-processed`) with zero PHP overhead. A Video.js React component powers playback on both the portal video details page and a dedicated, chromeless iframe embed page (`/embed/videos/{id}`).

**Tech Stack:** PHP 8.4, Laravel 11, PostgreSQL 16, MinIO, Nginx 1.25, Video.js 8, React 19, TypeScript, Tailwind CSS v4, Inertia.js v2.

**Spec:** [docs/architecture.md](file:///D:/Playground/wiz-video-platform/docs/architecture.md)

---

## Global Constraints

- **PHP Standards:** `declare(strict_types=1);` and `final class` on all new PHP classes, enforced by Laravel Pint.
- **TypeScript / React Standards:** Strict TypeScript (`tsc --noEmit`), React 19 functional components, Tailwind CSS styling, Localizer integration.
- **Security & Authorization:** Constant-time token verification using `hash_equals()`; `X-Internal-Secret` protection on internal endpoints; strict visibility enforcement (`public`, `unlisted`, `private`).
- **Nginx & MinIO Offload:** No `.ts` media segments or heavy video chunks may be buffered or streamed through PHP; Nginx must proxy directly to MinIO once authorized.
- **Test Integrity:** Zero failing tests across Go (`worker/...`) and Laravel (`panel/...`); Pint clean across all PHP files.

---

## Review Focus

1. **Token Tampering & Expiration:** A request with an altered `video_id`, altered expiration, or signature mismatch must fail with 403 Forbidden.
2. **Private Video Leakage:** A private video must reject playback requests from unauthorized users or tokens generated by a different tenant.
3. **Nginx Header Extraction:** Nginx must read `X-Tenant-Id` from the auth subrequest to resolve the MinIO multi-tenant object path `tenants/{tenant_id}/videos/{video_id}/hls/{asset}`.
4. **Iframe Framing Headers:** The embed endpoint (`/embed/videos/{id}`) must permit framing (`X-Frame-Options` relaxed, CSP `frame-ancestors *` for public/unlisted) while the authenticated portal remains protected against clickjacking.
5. **Video.js DOM Cleanup:** The React `VideoPlayer` component must cleanly dispose of the Video.js player instance on unmount to prevent memory leaks and orphaned media elements.

- [ ] **Step 3: Implement PlaybackAuthController and Register Route**

1. Create `panel/app/Http/Controllers/Api/Internal/PlaybackAuthController.php`:
   - Validates query params `video_id`, `token`, `expires`.
   - Fetches `$video = Video::withoutTenantScope()->find($videoId)`.
   - Checks `$video !== null` and `$video->status === VideoStatus::READY`.
   - Checks token validity via `PlaybackTokenServiceInterface::validateToken()`.
   - If token is missing/invalid, checks if user is authenticated and is tenant member:
     `$user = auth()->user() ?? auth('sanctum')->user();`
     `$user !== null && $user->isTenantMember($video->tenant)`
   - On success, returns `response('', 200)->header('X-Tenant-Id', $video->tenant_id);`
   - On failure, returns `response()->json(['error' => 'Playback unauthorized'], 403);`
2. In `panel/routes/api.php`:
   - Register route `Route::get('/v1/internal/playback/auth', PlaybackAuthController::class);`

- [ ] **Step 4: Update Nginx Configuration**

In `infrastructure/nginx/default.conf`:
- Add location for auth subrequest:
```nginx
    location = /internal-playback-auth {
        internal;
        proxy_pass http://panel:8000/api/v1/internal/playback/auth;
        proxy_pass_request_body off;
        proxy_set_header Content-Length "";
        proxy_set_header X-Original-URI $request_uri;
        proxy_set_header Host $http_host;
    }
```
- Add location for `/playback/`:
```nginx
    location ~ ^/playback/(?<video_id>[a-f0-9\-]+)/(?<asset_path>.*)$ {
        auth_request /internal-playback-auth;
        auth_request_set $tenant_id $upstream_http_x_tenant_id;

        # Proxy directly to MinIO videos-processed bucket
        proxy_pass http://minio:9000/videos-processed/tenants/$tenant_id/videos/$video_id/hls/$asset_path;
        proxy_http_version 1.1;
        proxy_set_header Host minio:9000;

        # CORS Headers for cross-origin HLS playback
        add_header Access-Control-Allow-Origin * always;
        add_header Access-Control-Allow-Methods 'GET, HEAD, OPTIONS' always;
        add_header Access-Control-Allow-Headers '*' always;

        if ($request_method = 'OPTIONS') {
            return 204;
        }
    }
```
